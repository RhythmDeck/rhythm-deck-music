Higher Quality (CRF 18)
Best visual quality, larger file size.
Use for premium content or archiving.

Balanced (CRF 23 – Recommended)
Best balance of quality and file size.
Perfect for web, social, and general use.

Smaller File (CRF 28)
Smaller file, more compression artifacts.
Use when size matters more than detail.

👉 Lower number = better quality 👉 Higher number = smaller file

What is HEVC (H.265)?
HEVC is a newer video format that creates much smaller files with little to no visible quality loss.

ON: Long videos, albums, concerts, archiving
OFF: Short clips, faster exports, older devices

⚠️ HEVC is slower but can reduce size by 30–50%
